#  Aurum Events – Générateur de devis événementiel

Aurum Events est une application web permettant de générer des devis personnalisés pour des événements (mariages, anniversaires, conférences, etc.).

## 🚀 Objectif du projet

Faciliter la création de devis professionnels avec une expérience utilisateur fluide et un design haut de gamme.

---

## 🧩 Fonctionnalités principales

- 🏠 Page d'accueil avec présentation de l’entreprise
- 📝 Formulaire de demande de devis
- 🔍 Page de vérification des informations
- 📄 Génération d’un devis dynamique
- 💰 Calcul automatique du prix
- 📥 Téléchargement du devis en PDF
- ✅ Popup de confirmation après téléchargement

---

## 🛠️ Stack technique

### Frontend
- React
- React Router
- HTML / CSS (design luxe noir & or)
- html2pdf.js

### Backend 
- Supabase
